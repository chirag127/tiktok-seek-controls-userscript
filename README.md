# TikTok Seek Controls

Arrow-key seeking, J/L jumps, frame nudges and speed steps with an on-screen readout.

## Install

Follow the [install guide](https://github.com/chirag127/userscript-install-guide), then install:

```
https://github.com/chirag127/tiktok-seek-controls-userscript/raw/main/tiktok-seek-controls-userscript.user.js
```

## Usage

Install; keys work on any video. Alt-less by design so it does not clash with TikTok shortcuts.

## Limits

- TikTok already binds some arrows on the feed
- Frame step depends on the element frame rate
- Speed resets if you reload without remembering enabled

## Risk

Clean: playback only.

Part of the [userscript collection](https://github.com/chirag127/userscript-install-guide).
